# 素材繪製需求包（給繪圖 Agent）

**主題：台灣的「市場」**——以傳統市場為主，夜市是其中一種。畫面要同時看得出傳統市場與夜市：

- **傳統市場**：遮雨棚、竹籃、蔬果、魚肉攤、乾貨。
- **夜市**：燈籠、小吃攤車、飲料。

共 24 項素材。

| 檔案 | 內容 |
|---|---|
| `manifest.json` | 每項的規格：任務類型、輸出尺寸、**文字規則 `text` 與允許的文字 `allowed_text`**、保留／移除／替換、**提示詞 `prompt` 與負面提示詞 `negative_prompt`**、注意事項、驗收標準、交付路徑 |
| `refs/<ID>-source.png` | 參考原圖（原始解析度） |
| `refs/<ID>-annotated.png` | 標註圖：**紅＝移除**、**綠＝保留**、**橘＝替換**、**藍＝介面區（留白）** |
| `refs/<ID>-context.png` | 這項素材在整張設計圖中的位置（藍框） |

參考圖由 `design/tools/make_asset_refs.py` 產生。修改規格請改這支程式，再重新執行。

---

## 一、執行步驟（每一項素材）

1. 讀 `manifest.json` 裡該項的所有欄位，並看過 `refs/` 裡的參考圖。
2. 依 `task` 決定做法：

   | task | 做法 | 允許改變的程度 |
   |---|---|---|
   | `inpaint` | 以 `source` 為底圖，只修改橘框（替換）和紅框（移除）的範圍 | **構圖、位置、比例都不能變** |
   | `extract` | 把角色或物件畫到透明背景上，被遮住的部分補完整；`replace` 有列出的道具照著換 | 姿勢、表情、造型、配色不變 |
   | `new` | 參考圖**只用來看構圖**，內容依 `prompt` 改成市場主題 | 藍框（介面區）必須留白 |

3. 以 `prompt` 當主要提示詞，`negative_prompt` 當負面提示詞。工具不支援負面提示詞時，把它改寫成「不要……」接在提示詞後面。
4. 依 `output` 輸出**剛好**這個尺寸的 PNG。背景寫「透明」的，四個角落必須完全透明。
5. 用 `accept` 逐條自我檢查，全部通過後存到 `deliver_to`。

框線重疊時，優先順序是**綠＞橘＞紅＞藍**。

## 二、共通規則

### 1. 文字規則：看素材是固定使用，還是會重複使用

每一項的 `text` 欄位會標明：

| `text` | 什麼素材 | 規則 |
|---|---|---|
| `fixed` | **固定使用**：只出現在一個地方，內容永遠不變。例如頁面背景、頁面標題、地圖標語、城市名稱 | **可以畫手寫字**，但只能畫 `allowed_text` 列出的文字。字要完全一致，用繁體中文，不能多也不能少 |
| `none` | **重複使用或旁邊有動態內容**：例如角色、Logo、圖示、預設圖、空狀態插圖、手機背景 | **不能有任何文字**。這些地方的文字由網頁產生，才能修改或顯示不同的資料 |

以下內容**一律由網頁產生，不要畫進任何素材**：

- 市場名稱
- 攤商名稱
- 數量、百分比、日期
- 狀態名稱
- 按鈕文字
- 表單說明文字
- 頁面副標題

這些內容會隨資料改變，或者之後可能調整。

### 2. 其他規則

1. **不能有介面元素**：按鈕、輸入框、卡片、圖釘、圖例都不要。只有 `allowed_text` 有列出的對話框才可以畫。
2. **不能有品牌標誌**，包含 Google 地圖圖示。文字裡寫「Google」可以，但不能畫標誌。
4. **解析度**：`output` 已經是顯示尺寸的 2 倍（Logo 是 4 倍）。
5. **小圖要重新精繪**，不要只是放大參考圖。

## 三、風格規範

`manifest.json` 的每個 `prompt` 都已經內含以下規範：

- **整體**：可愛 Q 版插畫，溫暖、熱鬧、親切的台灣在地市場。
- **時段**：傍晚到入夜（golden hour），燈籠剛點亮。這個時段同時適合傳統市場和夜市。
- **線條**：深咖啡色描邊 `#3B2A1A`，粗細一致。
- **上色**：平塗加柔和陰影，不要寫實、漸層光暈或 3D 效果。
- **主色**：
  - 暖橘 `#F08A3C`
  - 燈籠紅 `#E5484D`
  - 奶油白 `#FFF8E6`
  - 草綠 `#7CC46A`
  - 海藍 `#6DD7F2`
- **三花貓吉祥物**：出現在 A10～A14、A20、A21，花色要一致，以 A10 為標準：
  - 白底
  - 畫面左側的耳朵和頭頂偏左是橘色斑
  - 畫面右側的耳朵是深灰到黑色斑
  - 粉紅腮紅

## 五、特別注意

### A01 地圖：位置不能動

這張是在 `reference/map-v2/map-taiwan-clean.png` 上局部修改。網頁會在這張圖上標出每個市場的像素座標，所以海岸線和所有建築的位置都不能移動，只換掉橘框裡的建築。

驗收方式：把輸出縮小 50%，疊在 source 上，海岸線偏差應該在 2px 以內。

### A25 縣市徽章用底圖：重新畫，不需要和舊圖相同

網頁會在每個縣市放一個徽章，顯示攤商數和完成比例，點選後彈出該縣市的市場列表。底圖只是背景，要安靜、不搶眼。

- 參考圖只用來看畫風。版面看 `refs/A25-annotated.png`：
  - 藍框：22 個縣市徽章的大約位置，框內要是平坦、低細節的區域。
  - 橘框：北部要刻意放大，以及綠島、蘭嶼的位置。
- 北部放大約 1.5 倍，讓基隆、台北、新北、桃園、新竹的徽章放得開。
- 離島：
  - 澎湖照實際方向畫。
  - 金門、馬祖畫在左側海上，用虛線框表示不照比例。
  - 綠島、蘭嶼畫在台東外海，不放徽章。
- 沒有建築、地標、縣市界線、道路、文字。
- 交付後，徽章的實際像素位置由我在成品上標定。

### A03、A04、A05：重新畫，但構圖照參考圖

- 這三張的參考圖是夜市場景，只用來看構圖，內容要改成市場主題。
- 藍框是網頁放表單和標題的位置，要畫成低對比、少細節的背景，**藍框裡不能有文字**。
- A03、A05 的招牌和標語只能用 `allowed_text` 的文字。

### 不需要畫的東西

下面這些由網頁用 SVG 產生，**不要出圖**：

- 群聚標記
- 圖釘
- 市場類型圖示（傳統市場、夜市）
- 圖例
- 按鈕
- 市場名稱、攤商名稱等所有會隨資料改變的文字
