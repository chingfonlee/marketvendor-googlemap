# 測試（任務 10）

- 更新日期：2026-11-01
- 對應 [PLAN.md](PLAN.md) §6 任務 10：正式資料快照、縣市→市場→攤商連動、網址檢查、邊界案例，以及任務 9 的開發開關。
- 不裝任何套件：Node 端用內建的 `node:test`（Node 22），瀏覽器端是一頁自己跑的測試頁。

## 1. 怎麼跑

Node 端（資料、規則、紀錄格式），約 1 秒：

```bash
node --test "tests/*.test.mjs"
```

瀏覽器端（真的畫面、點選、版面），約 50 秒：

```bash
python tests/serve_tests.py
```

打開 <http://localhost:8766/>，頁面會自動跑完，最上面顯示「N 項全部通過」或失敗的項目和原因。

**跑的時候視窗要看得到**（不要最小化、不要切到別的分頁）。被藏起來的頁面瀏覽器不重繪，`ResizeObserver` 不會觸發，地圖和標籤尺寸的項目會失敗（任務 11 遇過，見 [ACCEPTANCE.md](ACCEPTANCE.md) §4）。

伺服器同時開 <http://127.0.0.2:8767/>。`127.0.0.2` 不是開發網址，網頁會當成正式環境；測試頁跑完開發環境的項目後，會自動到這裡跑「正式環境」的項目，結果合在同一頁。兩個都只聽本機。

測試伺服器的路徑：

| 路徑 | 內容 |
|---|---|
| `/` | 測試頁（`tests/browser/`） |
| `/web/…` | 正式網頁和正式資料 |
| `/fx/edge/…` | 同一份網頁，`data/*.json` 換成 `tests/fixtures/edge/`（邊界案例） |
| `/api/submissions` | 假的補交 API：收下紀錄回 `{ok: true}`。`GET /api/_received` 取回收到的，`POST /api/_fail` 讓下一次回 500，`POST /api/_reset` 清空 |

### 2.3 網址檢查（`tests/urlcheck.test.mjs`）

### 2.5 開發開關（`tests/env.test.mjs`＋瀏覽器測試，任務 9）

- 開發環境只有 `localhost`、`127.0.0.1`、`[::1]`、`*.localhost`、`*.test`；`localhost.example.com`、`mylocalhost`、`127.0.0.2`、區網 IP、`gm.test.example.com` 等都算正式環境。
- **正式環境無法開啟**：瀏覽器裡存了「全部關掉」也讀不到；補交頁存了模擬或關閉也一律送到 API；`devtools.js` 被手動載入也不會建立開關。瀏覽器端在 `127.0.0.2` 實際打開兩頁確認：沒有「開發」按鈕、不下載 `devtools.js`／`devtools.css`、畫面和操作都正常。
- 開發環境：沒存過設定時全部打開、補交是模擬送出；存的設定蓋過預設；設定壞掉或無痕視窗時退回預設。
- 每個開關關掉的效果（照 SVG_COMPONENTS §6）：底圖（底圖、標語、貓）、縣市標籤（標籤、圖例、清單版縣市卡片）、統計（進度卡）、清單（篩選、市場清單、攤商清單）、互動（地圖、選單、搜尋、狀態按鈕、市場清單拿不到焦點，攤商連結照常）。

- 正式環境的補交頁一律送到 API、顯示 Turnstile，存了模擬或關閉也一樣。

| 1 | 總覽頁，選到 0 家的市場 | 提示寫「這個範圍還沒有**全部的**攤商」，下面的「顯示全部狀態」按了沒作用 | 「這個市場還沒有攤商」（縣市是「這個縣市還沒有攤商」），不顯示按鈕；篩狀態造成的空清單照舊有按鈕（`web/js/panels.js` 的 `renderVendors`） |
| 2 | 補交頁，選到 0 家的市場 | 攤商選單寫「請選擇攤商」，但沒有任何選項 | 「這個市場沒有攤商」，選單鎖住（`web/js/submit.js` 的 `renderSelects`） |

目前的正式資料每個市場至少 20 家，碰不到這兩個情況；修正是為了之後某個市場的攤商全部被排除時也不出錯。

另外發現匯入程式和網頁的網址規則有兩個小差異，正式資料都沒碰到，先記下不改：

- 長網址的 `0x…` 十六進位：網頁不分大小寫，Python 只認小寫。Google 產生的都是小寫。
- `cid=` 後面是全形數字（`１２３`）：Python 的 `isdigit()` 會當成數字接受，網頁不接受。

開發開關的小現象（只在本機，不影響正式環境）：`devtools.css` 在頁面載入後才加進來，有開關關掉時重新整理，被關掉的元件會先出現一下才消失。
