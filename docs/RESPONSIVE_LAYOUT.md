## 1. 斷點

照建議的三段切，但版面只有兩套，依寬度和方向選用：

| 名稱 | 寬度 | 方向 | 版面 | 理由 |
|---|---|---|---|---|
| 手機 | < 768px | 任何 | **L** 清單版 | 放不下側欄；手機上地圖太小，使用者決定不放（決定 E） |
| 平板直向 | 768～1279px | 直向 | **L** 清單版 | 同上（決定 E） |
| 平板橫向 | 1024～1279px | 橫向 | **D** 緊湊 | 1024 寬扣掉兩欄最小 580px，地圖約 380px，標籤用精簡卡仍不重疊；版面和桌機一致 |
| 平板橫向（窄） | 768～1023px | 橫向 | **L** | 少見（縮小的瀏覽器視窗）；三欄放不下 |
| 桌機 | ≥ 1280px | 任何 | **D** | 照完成圖 |
| 橫放的手機 | 任何 | 橫向且高 < 560px | **L** | 三欄版地圖會小於 326px，標籤一定重疊；清單版整頁捲動，橫放也能用 |

CSS 的寫法（同一組條件也給 JS 用，避免兩邊判斷不一致）：

```css
/* 預設 D 版 */
:root { --layout: d; }
/* L 版：手機、平板直向、窄的橫向、矮的橫向 */
@media (max-width: 767px),
       (max-width: 1279px) and (orientation: portrait),
       (max-width: 1023px),
       (orientation: landscape) and (max-height: 559px) {
  :root { --layout: l; }
}
```

- JS 讀 `getComputedStyle(document.documentElement).getPropertyValue('--layout')` 決定要不要建立地圖，不另外寫一份 `matchMedia` 條件。
- 寬度 1280 以上但高度小於 560 的視窗低於最小支援（1280×720），會落到 L 版，可以用但不另外優化。
- 間距、字級、可點範圍依「指標類型」調整，不依斷點：`@media (pointer: coarse)` 時所有可點的地方至少 44px（觸控的 iPad 橫放走 D 版時也適用）。

## 2. 桌機（D 版，≥ 1280px）

照完成圖：頁首；左欄上進度卡、下篩選；中間地圖；右欄上市場清單卡、下攤商清單。整頁不捲動（`height: 100dvh; overflow: hidden`），左欄和右欄在欄內捲動。

### 2.2 尺寸

| 項目 | 數值 | 說明 |
|---|---|---|
| 頁首 | 高 72px；Logo 48；標題 20px 粗體、副標 12px；分頁按鈕高 40；補交按鈕高 44 | 完成圖是 92px，最小支援 720 高時太佔空間 |
| 外距 | 左右下 16px；頁首和內容之間 16px | |
| 欄距 | 16px | |
| 左欄 | `minmax(300px, 420px)` | 完成圖約 420 |
| 右欄 | `minmax(320px, 424px)` | 完成圖約 424 |
| 地圖 | 寬 = `min(可用高 × 2/3, 視窗寬 − 64 − 620)`，高 = 寬 × 1.5 | 底圖 2:3；620 是左右欄最小寬的和 |
| 卡片 | 圓角 16、白底、陰影照 `atoms` 的 `shadow` | |

CSS Grid：

```css
body[data-layout="d"] {
  --hdr: 72px;
  --map-h: calc(100dvh - var(--hdr) - 32px);        /* 頁首下 16 + 底部 16 */
  --map-w: min(calc(var(--map-h) * 2 / 3), calc(100vw - 64px - 620px));
  display: grid;
  height: 100dvh;
  overflow: hidden;
  grid-template-rows: var(--hdr) minmax(0, 1fr);
  grid-template-columns: minmax(300px, 420px) var(--map-w) minmax(320px, 424px);
  grid-template-areas: "hdr hdr hdr" "left map right";
  justify-content: center;   /* 欄都到上限後，多出的寬度平分在兩側 */
  column-gap: 16px;
  row-gap: 16px;
  padding: 0 16px 16px;
}
header      { grid-area: hdr; margin: 0 -16px; }   /* 頁首滿版 */
aside.left  { grid-area: left;  overflow-y: auto; }
main.map    { grid-area: map;   align-self: start; width: var(--map-w); aspect-ratio: 2 / 3; }
aside.right { grid-area: right; display: grid; grid-template-rows: auto minmax(0, 1fr); gap: 16px; }
```

- 地圖欄寬就是地圖寬，左右欄先長到上限，剩下的空白平分在兩側（`justify-content: center`）。
- 地圖由高度決定，所以視窗越矮地圖越小（§2.3）。
- 地圖框不加卡片外框。底圖的海（約 `#91EBFD`）和頁面底色 `#D6F3FD` 不同色，所以**地圖框四邊用 24px 的 `mask-image` 漸層淡出**，讓海面融進頁面底色，和完成圖一樣看不出邊界（決定 I）。**遮罩只套在底圖層 `.layer-base`**，不套在標籤層和疊加層：標籤離地圖邊緣最近只有約 9px（1024×768 的新北），套到整個地圖框會讓標籤邊緣也變淡。

## 3. 地圖顯示寬度和標籤重疊檢查（只有 D 版）

### 3.1 換算方式

和 `design/tools/label_overlay.ps1` 相同：卡片在螢幕上大小固定，換算成地圖單位是

```
地圖單位 = 螢幕 px × 1024 ÷ 地圖顯示寬度
```

檢查項目和 COUNTY_LABELS.md §3 相同：8 張卡片兩兩不重疊、不超出 viewBox、不碰兩個保留區。座標檔和保留區直接讀 `map-taiwan-base.labels.json`，**沒有修改**。檢查用的是暫存腳本（不放進 repo），邏輯就是上面的公式加矩形相交判斷。

### 3.2 最小地圖寬度

| 卡片 | 剛好不重疊 | 卡片間至少留 4px | 卡片間至少留 8px | 卡住的地方 |
|---|---|---|---|---|
| 桌機卡 136×92 | **555px** | 579px | 603px | 臺北和新北、臺北和桃園（上下差 170 單位）；新竹和標語保留區 |
| 精簡卡 88×54 | **326px** | 350px | 374px | 同上 |

### 3.4 卡片尺寸規則（決定 A）

```
量到的地圖顯示寬度 ≥ 565px → 桌機卡 136×92（兩行數字、有攤車圖示）
量到的地圖顯示寬度 < 565px → 精簡卡 88×54（一行數字、沒有圖示）
```

- 用 `ResizeObserver` 量地圖框的實際寬度（CSS px），在 `.layer-labels` 設 `data-size="desktop|compact"`。
- **不用螢幕解析度、`devicePixelRatio`、媒體查詢判斷**。同一台 1080P 螢幕，縮放 125% 或多了書籤列時地圖會小於 555px，必須維持精簡卡；只有量地圖本身才準。
- 每次地圖框尺寸改變（縮放瀏覽器、開關書籤列、拖動視窗）都重新判斷。
- 精簡卡高 54px，觸控時也大於 44px。

卡片之間很近（565px 時 1.8px），所以狀態樣式要遵守：

| 規則 | 內容 |
|---|---|
| 疊放順序 | **選取中和有焦點的卡片 `z-index` 放最上層**；光圈和焦點框寬 3px 以內，蓋到旁邊的卡片可以接受（旁邊的卡片在選取時本來就是變淡狀態） |
| 滑過 | 桌機卡**不放大**，只加深陰影和邊框色；如果要放大，最多 1.01 倍（565px 時已檢查，放大 1.01 倍仍不重疊）。精簡卡同樣不放大 |

### 4.7 DOM 和版面切換

同一份 HTML 給 D 版和 L 版用。L 版的畫面順序和 D 版的 DOM 順序不同，**不用 CSS `order` 硬排**（會讓 Tab 順序和畫面不一致），改由 JS 在切換版面時搬動節點：

| 節點 | D 版的位置 | L 版的位置 |
|---|---|---|
| 縣市卡片區（新元件） | `aside.left` 進度卡後面，`hidden` | 同一位置，顯示 |
| 搜尋框＋狀態按鈕 | `aside.left` 的篩選面板裡 | 搬到攤商清單前面 |
| 縣市選單、市場選單 | 篩選面板裡 | 留在原處，`hidden`（由縣市卡片和市場清單取代） |
| 狀態說明 | 篩選面板最下面，3 行直接顯示 | 跟著搜尋框＋狀態按鈕搬到攤商清單前面，收成「ⓘ 狀態說明」按鈕 |
| 大聲公貓 | 篩選面板最下面 | 搬到頁尾 |
| `main.map` | 中欄 | `hidden`，不建立 |
| 市場清單卡的「切換縣市 ⌄」 | 顯示 | `hidden`（由縣市卡片取代） |

- 只搬節點，不複製，所以 DOM 裡永遠只有一個搜尋框、一組狀態按鈕。
- 搬動時保留焦點：如果焦點在被搬的元件上，搬完後焦點仍在同一個元件。
- 版面切換（轉向、拖動視窗）時狀態不變，網址 hash 不變。

### 7.1 Tab 順序

**D 版（桌機、平板橫向）**：DOM 照 LAYER_ARCHITECTURE §1 的 `header → aside.left → main.map → aside.right`。

| # | 元素 |
|---|---|
| 1 | 「跳到攤商清單」略過連結（平常隱藏，取得焦點時出現） |
| 2 | 頁首：Logo（回首頁）、地圖總覽分頁、補交入口 |
| 3 | 搜尋框 → 縣市選單 → 市場選單 |
| 4 | 狀態按鈕：一組 `role="radiogroup"`，只佔一個 Tab 停點，用左右鍵切換 |
| 5 | 狀態說明（不可點，跳過） |
| 6 | 地圖標籤 8 個，照 labels.json 的順序（北到南：臺北、新北、桃園、新竹、臺中、臺南、高雄、臺東） |

### 7.2 清單版的焦點和朗讀

- 點市場列後，頁面捲到攤商清單，**焦點移到攤商清單的標題**（`tabindex="-1"`），讀屏軟體會唸出「臺北永春市場・攤商清單，20 家」。
- 點「回到頂端」後，焦點移到「選擇縣市」標題。「回到頂端」出現或消失時不改變焦點；它是一般按鈕，排在攤商清單之後，鍵盤使用者也可以用「跳到攤商清單」和標題跳轉。
- 選縣市、輸入搜尋、切換狀態時焦點不動；結果的筆數用 `aria-live="polite"` 唸出，例如「臺北市，61 家攤商」「找不到符合的攤商」。
- 縣市卡片的可讀名稱：「臺北市，3 個市場，61 家攤商」，選中時 `aria-pressed="true"`；「全台」是「全台，15 個市場，347 家攤商」。
- 市場列選中時加 `aria-current="true"`。

### 7.3 prefers-reduced-motion

`@media (prefers-reduced-motion: reduce)` 時：

| 動畫 | 改成 |
|---|---|
| 點標籤後地圖平移、回到全台（D 版） | 直接到位 |
| 縮放（按鈕，D 版） | 直接到位 |
| 標籤滑過（本來最多 1.01 倍，§3.4） | 不放大，只顯示焦點框和陰影 |
| 標語和貓淡出（D 版） | 直接隱藏 |
| 點市場後捲到攤商清單、回到頂端（L 版）；範圍改變後清單捲回最上面 | 直接跳到位置，不平滑捲動 |
| 骨架畫面的閃光 | 靜態灰塊 |

### 7.4 其他

- 地圖標籤的可讀名稱：「臺北市，3 個市場，61 家攤商」；選中時加 `aria-pressed="true"`。
- 地圖平面的容器 `role="group"`、`aria-label="縣市地圖"`；底圖 `<image>` 是裝飾，`aria-hidden`。
- 字級用 rem；瀏覽器字級放大到 200% 時，D 版的左欄、右欄允許捲動，L 版整頁捲動，都不截字。地圖標籤是固定 px，不跟著放大（否則會重疊）；L 版的縣市卡片跟著字級放大，放不下時卡片變高，不截字。

## 11. 驗收清單（任務 7 做網頁時逐條檢查）

用瀏覽器開發者工具的裝置模擬，每一條記錄通過或不通過。

### D 版版面

1. 視窗 1280×720、1366×768、1536×1024、1920×955、1920×1080：三欄版，整頁沒有捲軸，頁首 72px，欄距 16px。
2. 上述尺寸的地圖寬度和 §2.3 的表相差在 2px 以內，比例 2:3，不變形、不裁切。
3. 1280×720：左欄放不下時左欄內捲動；攤商清單標題和表頭固定、全部列出、在欄內往下捲（沒有分頁器）；市場清單卡不超過右欄 45%。
3a. 地圖邊緣：底圖四邊 24px 淡出到頁面底色，看不出地圖框；標籤和縮放鈕沒有被淡出。換縣市或篩選時，攤商清單捲回最上面。
4. 視窗高 < 900 時沒有女孩插畫和大聲公貓；≥ 900 時有。
5. 1024×768 橫向：三欄緊湊版，地圖約 380px，精簡卡。
6. 市場清單卡標頭的「切換縣市 ⌄」：點了展開「全部縣市 (8)」加 8 個縣市；選了之後地圖標籤、左側縣市選單、進度卡一起改；Esc 關閉、焦點回到按鈕；卡片不會收合。

### 標籤（D 版）

7. 卡片尺寸依**量到的地圖顯示寬度**切換：≥ 565px 是桌機卡 136×92，< 565px 是精簡卡 88×54（看 `.layer-labels` 的 `data-size`）。逐一檢查：
   - 1920×955（地圖 567）→ 桌機卡；1920×920（地圖 544）→ 精簡卡；1536×1024（地圖 613）→ 桌機卡；1440×900（地圖 531）→ 精簡卡。
   - 在 1920×955 把瀏覽器縮放改成 125%（地圖小於 555）→ 變成精簡卡；改回 100% → 變回桌機卡，不需要重新整理。
   - 程式裡沒有用 `screen.width`、`devicePixelRatio` 或媒體查詢判斷卡片尺寸。
8. 在 §3.3 表中每一列的情況（用模擬尺寸做出對應的地圖寬度）截圖：8 張卡片不重疊、不超出地圖、不壓到三個保留區（`headline`、`mascot`、`controls`）。
9. 1920×955 選取臺北市：選取中和有焦點的卡片在最上層，光圈和焦點框不被新北、桃園蓋住。
10. 桌機卡滑過時不放大，或放大不超過 1.01 倍；放大時仍不碰旁邊的卡片。
11. 標籤在任何縮放倍率下維持固定螢幕大小。

## 13. 統計報表頁（第二版，2026-11-01）

- 依據：示意圖 `design/reference/stats-mockup-v2.png`、`stats-mockup-v2-mobile.png`；PLAN §2.1；資料規則 `design/asset-briefs/stats-page-assets.md` §五。
- 版面參考：`design/svg/pages/stats-desktop.svg`（1440×900）、`stats-mobile.svg`（390 寬），由 `design/tools/build_stats_svg.py` 產生，數字讀 `web/data/markets.json`。
- 統計頁沒有地圖，所以只分兩種版面，用**視窗寬度**判斷（不用量地圖寬度）。

### 13.1 斷點

| 寬度 | 版面 |
|---|---|
| ≥ 1024 | **2×2**：①全台登錄進度、②各縣市提交比例在上，③市場類型比較、④最強友善力市集在下 |
| < 1024 | **單欄**：①②③④ 由上到下 |

### 13.2 尺寸

| 區塊 | 2×2（1440×900 為例） | 單欄（375～390 寬） |
|---|---|---|
| 頁首 | 和地圖頁相同，72 高；分頁「統計報表」選中 | 和地圖頁 L 版相同，56～64 高＋分頁列 48 |
| 外邊距、卡片間距 | 左右 24、間距 16 | 左右 16、間距 16 |
| 卡片 | 兩欄等寬（1440 時 688）；上排 380 高，下排 330 高。**同一排兩張卡片一樣高**，以內容多的那張為準 | 全寬，高度照內容 |
| ① 甜甜圈 | 直徑 264、環寬 40；中間百分比 44px | 直徑 140、環寬 26；中間百分比 28px |
| ① 圖例 | 3 列，每列：色點、名稱、家數、百分比 | 3 列，**不顯示百分比**（寬度不夠，「審核中」會和數字重疊） |
| ② 長條 | 每列 34 高、長條 18 高；縣市名 16px、百分比 18px | 每列 34 高、長條 14 高；縣市名 14px、百分比 15px |
| ③ 類型 | 3 欄等分；圖示 80、甜甜圈直徑 100 | 3 欄等分；圖示 56、甜甜圈直徑 68 |
| ④ 市場列 | 每列 72 高；類型圖示 40；右邊留給大聲公貓（200 寬） | 每列 64 高；類型圖示 36；貓縮到 72 放在標題列右邊 |
| 背景樹叢 | 左下、右下各 320×240，在卡片後面 | 各 160×120 |

- **1024～1279 寬**（卡片約 430 寬）：① 甜甜圈直徑 190、中間 34px、貓 150 寬；④ 大聲公貓 140 寬。不然圖例會被貓擋住（2026-11-01 實測 1024×768 發現）。
- **1280～1439 寬**：① 的貓 180 寬。圖例裡的「審核中」在這個寬度會換行、圖例變高，貓 220 寬會壓到圖例上框（2026-11-01 任務 17 測試發現）。
- **斷點寫法**：CSS 不寫「`min-width: 1024px` 和 `max-width: 1023px` 各一組」。螢幕縮放不是整數時，寬度可能是 1023.5，兩組都不符合、退回桌機大尺寸（任務 17 發現）。改成 `max-width: 1279px` 先套縮小尺寸，後面的 `max-width: 1023px` 再蓋成單欄。
- 縣市變多時，② 每列高度不變，卡片變高；同一排的 ① 跟著變高，內容垂直置中。
- 可點範圍：分頁、進度卡連結至少 44 高。圖表本身不能點（第一版）。

### 13.3 精簡版分頁列（L 清單版，地圖頁和統計頁共用）

- 位置：頁首正下方，全寬，48 高，和頁首一起 `sticky`。
- 兩格各佔一半，每格圖示 20＋文字 15px，置中；選中的格子文字變主色、底下 4px 主色底線。
- 用 `<nav aria-label="分頁">`，選中的是 `aria-current="page"`。
- 參考：`design/svg/components/stats-header-mobile.svg`。

### 13.4 驗收清單

1. 1440×900、1280×720、1024×768：2×2，沒有橫向捲軸；同一排卡片一樣高。
2. 375×667、360×640：單欄，順序 ①②③④；沒有橫向捲軸；分頁列在頁首下方，捲動時固定。
3. 768×1024：單欄，卡片全寬。
4. 每條長條總長一樣、左右對齊；三段加起來剛好填滿。
5. 手機圖例的「審核中」不和數字重疊。
6. 手機字體放大時，市場名稱（例如「興國公有零售市場」）換行，不被切掉。
