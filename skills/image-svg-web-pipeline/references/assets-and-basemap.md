# 底圖、素材生圖、疊加位置

Claude 不自己生圖。Claude 的工作是：寫清楚要什麼圖、驗收交回來的圖、把圖接進網頁。

## 1. 底圖檢討（先比對，再決定）

拿現有底圖和設計圖逐項比對，寫成 `docs/BASEMAP_REVIEW.md`：

| # | 項目 | 現行 | 設計圖 | 影響 |
|---|---|---|---|---|

常見項目：外形正不正確、主體元素（山脈等）會不會壓到要放標籤的地方、界線、地標和建築、離島、構圖留白（標語、吉祥物、縮放鈕放哪）。

每個差異給建議，再列「要人決定的事」（例如：島內放不放地標？畫不畫界線？離島留不留？），用選項問。決定後寫進文件 §「使用者決定」並標日期。**這一輪不產生圖片。**

## 2. 生圖需求包（給生圖 Agent）

放在 `design/asset-briefs/`：

| 檔案 | 內容 |
|---|---|
| `README.md` | 執行步驟、共通規則、風格規範、素材總覽表 |
| `manifest.json` | 每項素材一筆（欄位見下） |
| `refs/<ID>-source.png` | 參考原圖 |
| `refs/<ID>-annotated.png` | 標註圖：**紅＝移除、綠＝保留、橘＝替換、藍＝介面區（留白）**；重疊時 綠＞橘＞紅＞藍 |
| `refs/<ID>-context.png` | 這項素材在整張設計圖中的位置 |
| `<ID>-vN-prompt.md` | 單項重做時的提示詞（例如底圖 v2、v3） |

參考圖用腳本產生（`make_asset_refs.py`），改規格改腳本。

### manifest 欄位

```json
{
  "id": "A25", "file": "map-taiwan-base.png", "priority": "P0",
  "task": "inpaint | extract | new",
  "title": "…", "source": "reference/…png", "crop": [x0, y0, x1, y1],
  "output": { "width": 2048, "height": 3072, "background": "不透明 | 透明" },
  "text": "none | fixed", "allowed_text": [],
  "keep": [], "remove": [], "replace": [], "notes": [],
  "prompt": "…", "negative_prompt": "text, letters, … map pins, markers, UI elements …",
  "accept": ["尺寸剛好 …", "沒有任何文字", "…"],
  "deliver_to": "design/assets/final/…"
}
```

- `task`：`inpaint` 構圖位置比例都不能變，只改框內；`extract` 角色畫到透明背景補完整；`new` 參考圖只看構圖。
- `text`：`fixed`（只出現一處、永遠不變，可以畫 `allowed_text` 裡的字）／`none`（會重複使用或旁邊有動態內容，不能有任何字）。
- 名稱、數字、日期、狀態、按鈕文字**一律由網頁產生**，不畫進任何素材。不畫介面元素、圖釘、品牌標誌。
- `output` 是顯示尺寸的 2 倍（Logo 4 倍）。
- 風格規範寫進每一個 `prompt`（線條色、主色 hex、畫風、吉祥物花色標準），生圖 Agent 不用另外讀。

## 3. 驗收交付的圖

逐條對 `accept` 檢查，寫成表格：

| 驗收項目 | 結果 |
|---|---|
| 尺寸、透明／不透明、位元深度 | 用腳本讀，不用目測 |
| 外形照參考 | 疊圖（50% 透明疊在參考上）給人看 |
| 不該有的東西（文字、地標、圖釘） | ✅／❌ |
| 留白區有沒有被佔 | 把保留區框畫在圖上 |
| 要放標籤的地方是否平坦 | 框出來看 |

不通過的寫回饋到 `asset-briefs/feedback/`，出下一版提示詞。人也可能直接提供自己的圖取代——那就照同樣清單驗收，接受就好。

## 4. 放大、轉檔、鎖定

- 解析度不夠時用超解析放大（FSRCNN 之類），把方法和參數記在 `UPSCALE.md`。一般雙三次插值不會增加細節，跟瀏覽器自己放大差不多。
- 原圖、前一版都留備份（`assets/review/<ID>/…`），也在 git 裡。
- 記錄正式底圖的 **SHA-256**（文件和座標檔都寫）。
- 網頁用的圖由 `scripts/build_web_assets.py` 轉成 WebP（品質 80 左右），不要手動轉。
- **座標系統固定用原圖尺寸的 viewBox**（例如 `0 0 1024 1536`）。之後換放大版，viewBox 和所有座標都不用改。

## 5. 疊在圖上的元素位置（標籤、熱點）

1. 座標檔放在底圖旁邊：`map-base.labels.json`，內容有 `basemap`、`basemap_sha256`、`viewBox`、`label_size`（各尺寸的 px 和換算成 viewBox 單位）、`reserved`（保留區矩形）、`labels`（每個的中心點）。
2. 寫一支疊圖工具（`label_overlay`），把標籤用真實尺寸和真實數字畫在底圖上，桌機、手機各一張預覽。
3. 用最擠的情況檢查（例如縮放 1 倍、最小地圖寬度）：**互相重疊、超出邊界、碰到保留區**三項都要是「無」。在一個範圍內逐 1px 掃地圖寬度，不要只測兩個點。
4. 標籤在螢幕上維持固定大小，地圖越小標籤佔的地圖範圍越大——所以要把 px 換算回 viewBox 單位再算重疊。
5. 網頁載入時比對 `basemap_sha256` 和實際底圖，不一致就在開發面板顯示警告。換底圖時一定要重新檢查座標。

交付物：座標表、兩張疊圖、檢查結果表，停下來讓人看。
